Check a model before you load it

Enter a model from Hugging Face to see whether its files can run code on your machine, what Hugging Face's scanners found, and what its model card leaves out.

Write owner/model, paste a huggingface.co link or a pkg:huggingface Package URL. Add @revision to check a specific commit.

Try: (a test repository with deliberately malicious files: mcpotato/42-eicar-street)

What it checks

  • Hugging Face’s own scans. Hugging Face runs uploaded files through the ClamAV antivirus and lists the imports inside pickle files, highlighting suspicious ones (Hugging Face docs). The checker shows which files were flagged.
  • File formats. A pickle file, and formats built on pickle such as PyTorch .bin, .pt and .ckpt, can run code the moment it is loaded. Safetensors, GGUF and ONNX store weights without code. Keras files can contain layers that run code, and Keras’s safe mode has been bypassed before (JFrog).
  • Custom code. A model that needs trust_remote_code=True runs Python from its repository on your machine.
  • Model card, licence and training data. Knowing where the training data came from is the first defence against poisoning. A model card that does not say is a reason to ask.
  • Base model. Fine-tunes, quantised versions and merges inherit whatever is in the model they came from, so the checker links to it.
  • The exact version. It gives you the commit to pin, so a later change to the repository cannot reach you, and the Package URL (pkg:huggingface/…) to record the model in an ML-BOM.

What it cannot tell you

The checker looks at what a repository publishes, not at what the model learned. A model can pass every check and still carry a backdoor planted through its training data: in one study, about 250 documents were enough. Finding that means testing how the model behaves, as described in the defence checklist.

Hugging Face’s scanners are best-effort and catch known patterns. A clean scan is evidence, not proof.

Privacy

The check runs in your browser. When you press the button, your browser asks Hugging Face’s public API about the model you entered. Nothing is sent to this site and nothing is stored. Hugging Face receives the request as it would any visit to its website, under its own privacy policy.

The checker reads public information only. It cannot see private models, and for gated models it shows what Hugging Face shows to anyone.
