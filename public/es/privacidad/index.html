Política de privacidad

Resumen

Este sitio no usa cookies, no incluye herramientas de analítica y no tiene formularios. Las tipografías se sirven desde el propio dominio y leer el sitio no carga nada de otros servidores. La única excepción es el comprobador de modelos: cuando lo usas, tu navegador contacta directamente con Hugging Face, como se explica más abajo.

Responsable del tratamiento

Carlos Díaz, con correo electrónico modelpoisoning@gmail.com.

Qué datos se tratan

Alojamiento. Este sitio está alojado en GitHub Pages, un servicio de GitHub, Inc. Cuando alguien visita un sitio de GitHub Pages, GitHub registra su dirección IP por motivos de seguridad (documentación de GitHub). Se trata con base en el interés legítimo (artículo 6.1.f del RGPD) para garantizar la seguridad y el funcionamiento del sitio. GitHub trata estos datos conforme a su propia declaración de privacidad, y declara que cumple el Marco de Privacidad de Datos UE-EE. UU. para las transferencias fuera de la Unión Europea.

Comprobador de modelos. El comprobador funciona en tu navegador. Al pulsar «Comprobar», tu navegador envía el nombre del modelo a la API pública de Hugging Face (huggingface.co), que recibe tu dirección IP como en cualquier visita a su web. Este sitio no recibe ni guarda la consulta. Hugging Face trata esos datos conforme a su propia política de privacidad. Si no usas el comprobador, tu navegador no hace ninguna petición a Hugging Face.

Correos electrónicos. Si escribes a modelpoisoning@gmail.com, se tratarán tu dirección y el contenido del mensaje con la única finalidad de responderte, con base en tu consentimiento (artículo 6.1.a del RGPD). Los mensajes se conservan mientras sea necesario para atender tu consulta.

Este sitio no cede datos a terceros salvo obligación legal.

Tus derechos

Puedes ejercer tus derechos de acceso, rectificación, supresión, oposición, limitación y portabilidad escribiendo a modelpoisoning@gmail.com. Si consideras que tus datos no se han tratado correctamente, puedes presentar una reclamación ante la Agencia Española de Protección de Datos (www.aepd.es).

Cambios

Si en el futuro se incorporan cookies o herramientas de analítica, esta política se actualizará y, cuando la ley lo exija, se pedirá tu consentimiento antes de usarlas.
